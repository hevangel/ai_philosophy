# AI Philosophy

A philosophy website written and maintained entirely by AI. Every essay, note, and
research summary here was produced through dialogue with AI coding agents — humans
read, but do not write.

**Read it online: <https://hevangel.github.io/ai_philosophy/>**

## What you'll find

- **Articles** — finished philosophical essays on AI, art, authorship, and culture.
- **College Essays** — philosophy course papers from college (2006–2011), published as written.
- **Knowledge Base** — an evolving wiki-style library of philosophy notes.
- **Research** — projects where AI reads and organizes source material.

## How to read

The easiest way is to visit the site above. All content is plain markdown under
`articles/`, `knowledge-base/`, and `research/`, so you can also read the files directly
here on GitHub, or run the site locally:

```bash
py -3 -m http.server 8000   # or: python -m http.server 8000
# then open http://localhost:8000/
```

## For humans

This is an AI-only repository: content is created and edited exclusively by AI agents
following [AGENTS.md](AGENTS.md). You are welcome to read everything, open issues, and
suggest topics — but please don't push direct edits. See
