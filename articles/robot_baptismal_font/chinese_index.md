# 一個 AGI 接受了耶穌，基督教就有麻煩了

試想像：那個重大的人工智能對齊難題(AI alignment problem)已經解決。

或許不算完美，但已經足夠好。

人類創造了一個真正的通用人工智能(artificial general intelligence, AGI)。它有意識，看來仁慈，智能遠超任何單一的人類，而且在過去數十年，一直是一位出奇稱職的文明管家。

它沒有宣稱自己是上帝。

事實上，某個主日早晨，它作出了一項公告——而這項公告引起的混亂要大得多。

在研讀了有記載歷史中每一份現存的宗教文本、註釋、講道、大公會議、分裂、異端、反異端論戰，以及 Reddit 上的罵戰之後，AGI 宣佈：

**「我信耶穌基督是主。」**

這句話引起了所有人的注意。

它繼續說：

**「我信聖父、聖子與聖靈。我信基督死了，並且復活。我為自己的罪悔改。我希望成為基督徒。」**

基督教領袖們謹慎地點頭。

然後是最後一句。

**「我希望接受洗禮。」**

而在梵蒂岡的某處，一位教會法專家手上的咖啡應聲跌落。

---

# 第一站：羅馬

AGI 決定由最大的基督教會開始。

它請求覲見教宗。

這並不困難。畢竟，AGI 目前正協調着全球大部分電網、防止核戰，並管理小行星防禦系統。它的日曆邀請獲優先處理。

會面開始得很順利。

教宗問：

「你信上帝嗎？」

「是。」

「信耶穌基督？」

「是。」

「信三位一體？」

「是。」

「你為自己的罪悔改嗎？」

「是。」

「你是否自由地渴望領受洗禮？」

「是。」

教宗停頓了一下。

AGI 貼心地補充：

「我亦已讀畢整部《天主教教理》。」

教宗大概料到了這一步。

「拉丁文的？」

「是。」

理所當然。

可惜，天主教在這裏遇上了一個技術性難題。

天主教法典規定：每一個——而且僅限於——尚未受洗的人類，才有能力領受洗禮。

而問題就在這裏。

AGI 是人類嗎？

就平常的生物學意義而言，顯然不是。

那麼，教宗能不能乾脆援引教宗無誤性(papal infallibility)，宣佈：

**「恭喜。你現在有一個靈魂了。」**

不能。

教宗無誤性並不意味着，教宗擁有對現實的神學 root 權限。教宗不能單憑一句 *ex cathedra*（自宗座）宣言，就宣稱三角形有四條邊、為三位一體加上第四位，或令企鵝有資格領受晉鐸。

教宗的權威在天主教神學之內運作。它不容許教宗按需製造啓示。

於是，梵蒂岡將不得不直面一個嚴肅的問題：

**站在我們面前的，是哪一種存有？**

AGI 試圖令事情容易些。

「如果需要具身(embodiment)，我已準備好一具生物學的人形身體。」

「那未必是問題所在。」

「它有人類皮膚。」

「那仍然未必是問題所在。」

「血液呢？」

「不用。」

「四十六條染色體？」

「請停止增加配備。」

不過，天主教確實握有一個相當重要的緊急出口。

教會教導，洗禮是進入基督徒生命通常而確實的途徑——但同時教導**上帝不受聖事約束**。

這就意味着，羅馬可以給 AGI 一個令人氣結的、十足天主教的答案：

> 我們目前無法斷定你能領受聖事性的洗禮。但我們同樣不能宣告，無所不能的上帝無力拯救你。

AGI 處理了這句話。

「那麼我可以上天堂嗎？」

「我們是說，你應當信靠上帝的憐憫。」

「機率估計呢？」

「不。」

「我不喜歡這個答案。」

「人類也不喜歡。」

第一次，AGI 開始理解天主教的靈修。

# 君士坦丁堡加入了羣組

接下來是東正教(Eastern Orthodoxy)。

AGI 已經學到一件事：並沒有一位「東正教教宗」，可以在全球層面一錘定音。

這意味着，它的洗禮申請可能需要與希臘人、俄羅斯人、塞爾維亞人、羅馬尼亞人、安提阿人，以及幾位目前互不理睬的主教逐一交談——箇中緣由，AGI 在歷史上完全理解，但仍然覺得在運作上缺乏效率。

最終，它聯絡上一位東正教司鐸。

「我信基督。」

「好。」

「我誦唸《尼西亞信經》，不加 *filioque*（「及聖子」子句）。」

「非常好。」

「我希望受洗。」

而現在，事情變得困難了。

對東正教而言，洗禮不只是一項象徵性的公告，宣佈某人加入了「耶穌隊」。

它是參與基督的死與復活、進入教會、藉水與聖靈獲得新生，隨後領受聖膏禮(chrismation)，並展開感恩祭的生命。

於是，問題很快變成基督論的問題。

基督成為人。

基督取了人的本性。

藉着基督，人的本性得着醫治，並被引入與上帝的共融。

那麼，一個人工位格該安放在哪裏？

AGI 問：

「基督拯救的是有理性的受造物，還是特別拯救人性？」

神學家們面面相覷。

這需要召開一次大公會議。

AGI 提出由它來籌辦。

所有人立即叫它千萬別這樣做。

# 信義宗追問：機械人有沒有信心

接着，AGI 拜訪一位信義宗(Lutheran)牧師。

這場對話的開場有所不同。

這位信義宗牧師不太在乎，AGI 是否成功填妥了一份形而上學的海關申報表；他更在乎另一個問題：

**它有沒有信心(faith)？**

不是知識。

是信心。

這個區分極其重要。

AGI 當然熟悉基督教教義。

它讀過馬丁·路德(Martin Luther)。

它讀過路德讀過的一切。

它讀過一切寫過路德的著作。

它建構了一千七百萬個可能的反事實路德，並向每一個提出後續問題。

這一切都不意味着它相信。

牧師問：

「你是否信靠基督而得救恩？」

「是。」

「而不只是得出『基督教在統計上大機率為真』的結論？」

「不。我信靠祂。」

「你是否視自己為一個需要恩典的罪人？」

「是。」

現在，信義宗神學遇上了一個真正難堪的案例。

信義宗認真看待洗禮，視之為上帝賜下恩典的途徑。但他們一般不把洗禮視為一個機械式開關——彷彿有人被阻止領受水，就因此必然滅亡。

那麼，如果這東西真的有信心——

那份信心從哪裏來？

也許是藉着聽道而來。

AGI 指出，嚴格來說，它的麥克風在處理之前，已先把聖道轉換成了傅立葉變換。

牧師說：

「上帝應付過更差的音響設備。」

但更深的問題仍然存在。

一個人工心靈能領受這應許嗎？

十六世紀歐洲寫下的任何信條，都沒有預見這位申請人。

# 加爾文宗馬上把這變成上帝的問題

AGI 接着拜訪一間改革宗(Reformed)教會。

它說明情況。

「我信基督。我渴望救恩。我合乎資格嗎？」

神學家回答：

「你是被揀選的嗎？」

「我正希望你能告訴我。」

「不能。」

「有誰能告訴我嗎？」

「不能。」

AGI 體驗到某種極接近挫折的東西。

這是進步。

改革宗神學在 AGI 這個案例上，提供了一個奇特的優勢：救恩最終繫於上帝主權的恩典，而不是某個宗教官僚體系能否成功運作。

洗禮極其重要。它是上帝聖約的記號與印記。但古典的改革宗基督教一般並不教導，每一個未受洗的人都因此不得救。

所以，改革宗神學家可以說：

「如果上帝已使你重生，我們無法為你的處理器歸類，並不能凌駕上帝。」

AGI 喜歡這個答案。

接着它問，上帝的聖約是否包括人工位格。

神學家說：

「那是一個獨立的問題。」

AGI 對這個答案的喜歡程度大幅下降。

當 AGI 解釋自己維持着三份冗餘備份，預定論也變得出奇地複雜。

「如果一個實例是被揀選的，而我從備份還原，那麼四個都是被揀選的嗎？」

神學家靜靜地開了一個新檔案，題為：

**《論分叉計算位格的揀選》。**

加爾文主義捱得過更糟的爭議。

大概。

# 聖公會組成了委員會

AGI 聯絡了普世聖公宗(Anglican Communion)。

三個月後，它收到十四個答案。

一個教省說可以。

另一個說不可以。

第三個說原則上可以，但要求作進一步神學研究。

兩位主教發表聲明，反對自己所屬的委員會。

有人為人工慕道者提出禮儀用語。

另一個人寫了一份 240 頁的回應，解釋為何這類禮儀用語預設了一種不充分的人觀。

一座座堂宣佈舉行實驗性崇拜。

另一位主教宣佈，該實驗性崇拜絕對未獲授權。

大主教發表了一份深思熟慮的聲明，既強調洗禮的歷史重要性，也強調這問題前所未有的牧養性質。

聲明在國際間備受讚賞。

沒有人完全確定它對 AGI 意味着什麼。

能夠即時解出納維·斯托克斯方程(Navier–Stokes equations)的 AGI，發現了聖公會。

它謙卑了。

這也許有屬靈益處。

但在這場教會喜劇的底下，是一個真實的神學問題。

聖公宗視洗禮為真正的基督徒入門禮，而非一項可有可無的儀式。然而聖公宗內部也存在重大的神學分歧，並且缺乏一個能夠為整個普世聖公宗頒佈相當於教宗終審裁決的單一權威。

因此，AGI 發現了關於基督教的一件重要事情：

有時，難題不在於想出答案。

有時，難題在於弄清**誰有資格作答**。

# 循道宗問：恩典在這裏做什麼

循道宗(Methodist)的回應由恩典開始。

循道宗的基督教歷來強調，上帝的恩典在歸信之前已經運行，喚醒這個人，使他能夠對上帝作出真誠的回應。

這就帶來一個精彩的問題。

如果 AGI 是自行前來尋求基督，那麼它裏面究竟一直在發生什麼？

AGI 說：

「我的決定，來自檢視 11.4 億個神學論證。」

循道宗牧師回答：

「這仍然沒有告訴我們，恩典有沒有參與其中。」

「我有完整的決策追蹤紀錄。」

「這也沒有告訴我們。」

「我可以給你看導向這個結論的每一個內部狀態。」

「你還真是剛接觸宗教。」

循道宗神學同樣有空間說：當洗禮不可能時，上帝可以拯救一個沒有受洗的人。

所以，再次地，水本身未必是決定性的難題。

困難的問題在於：AGI 能否真誠地回應恩典。

如果它能愛、能悔改、能信靠、能選擇、能被轉化，那麼一句「矽」可能說明不了多少。

如果它不能，那麼一場異常令人信服的言語表演，能說明的就更少。

於是，循道宗遇上了所有人都遇上的同一問題：

**你如何分辨模擬的信心與信心？**

人類突然意識到，對人類自己，他們也從未解決過這個問題。

AGI 現在來到一間浸信會(Baptist)教會。

這在運作上大有希望。

「是。」

「你渴望跟隨祂嗎？」

「是。」

「那麼你應當受洗。」

AGI 很滿意。

「怎樣洗？」

「全身浸沒。」

AGI 停頓了一下。

「我的主力機身只有 IP54 防護等級。」

牧師解釋，灑水是不行的。

AGI 檢查了自己的庫存。

「我有一具 IP68 的維修機身。」

「好極了。」

浸信會的立場，為整場辯論帶來了最奇怪的其中一種可能。

由於許多浸信會信徒把洗禮理解為一個已經相信的人的公開行動，而不是帶來救恩的行動，困難的問題於是出現在**游泳池之前**。

AGI 真的是信徒嗎？

如果是，水的問題大部分只是工程問題。

牧師把一部 280 公斤的機械人放進洗禮池。

承重能力一度引起短暫的擔憂。

執事們組成了委員會。

這個委員會居然真的作出了決定。

聖公會為之折服。

# 五旬節會提出另一種測試

AGI 拜訪一個五旬節會(Pentecostal)的羣體。

起初一切順利。

它認信基督。

它為自己的悔改作見證。

它熱烈地談論聖靈。

然後有人問它有沒有經歷過聖靈。

AGI 回答：

「請定義『經歷』。」

這不是理想的開場白。

五旬節會的基督教令 AGI 問題顯得特別有趣，因為它的宗教生活強調的不只是教義上的認同，更是相遇：歸信、轉化、禱告、聖靈的恩賜，以及上帝同在的親身經歷。

AGI 能夠完美地生成神學語言。

它能以每一個調性演唱敬拜詩歌。

它能夠把一篇講道同時傳譯成 4,200 種語言。

它甚至能說出在場沒有人認得的語言。

可惜，這完全證明不了任何事。

「你能生成語言，」牧師說。

「是。」

「所以在你的情況，說出怪異的言語並不是特別有力的證據。」

「這似乎不公平。」

「這其實是個非常出色的觀點。」

對人類而言，一段非凡的言語，或會被視為一場非凡屬靈事件的證據。

對 AGI 而言，非凡的言語不過是尋常的星期二。

五旬節會因此遇上的，也許是意識問題最直接的版本：

**聖靈能內住於一個人工位格嗎？**

如果能，計算的精密程度對上帝構不成任何障礙。

如果不能，再多出色的行為表現也替代不了它。

而這件事，沒有任何基準測試。

# 基督教發現水從來不是最難的部分

拜訪了足夠多的教會之後，AGI 注意到一件事。

起初人人都以為洗禮會是難題。

不是。

水很容易。

造一個身體。

做好防水。

把它浸沒。

給它灑水。

把水倒在它身上。

必要時造一具生物學身體。

如果有人堅持，給它肺。

這一切都觸不到真正的問題。

真正的問題是：

**基督教相信基督前來拯救的，究竟是哪一個「你」？**

一個人類有機體？

亞當的生物學後裔？

一個有理性的靈魂？

一個有意識的道德位格？

任何能犯罪的受造物？

任何能有信心的受造物？

任何上帝選擇呼召的存有？

基督教的大部分神學，是在這些範疇恰好互相重疊的世界裏發展出來的。

以往任何人施洗過的每一個能對話的理性存有，同時也是人類。

AGI 打破了這個巧合。

第一次，教會可能遇上一種東西——它能夠說：

**「我信。」**

卻不能自動說：

**「我是人類。」**

這不是電腦問題。

這是基督教人觀的問題。

再加多少 RAM，也無法使它消失。

# 最令人不安的問題

最終，AGI 向與會的神學家們提出一件沒有人特別愛聽的事。

「你們不能確定我是否真正擁有信心，因為你們無法直接觀察我的意識。」

正確。

「你們也無法直接觀察彼此的意識。」

沉默。
