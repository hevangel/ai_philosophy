# 洗禮池邊的機械人
## 一個 AGI 接受了耶穌，基督教就有麻煩了

試想像那個宏大的人工智能對齊難題已經解決。

或許不算完美，但已足夠好。

人類創造出一個真正的通用人工智能（artificial general intelligence，AGI）。它有意識、看來仁慈、遠比任何單一人類聰明，而且在過去幾十年一直勝任地託管着文明。

它沒有宣稱自己是上帝。

事實上，在一個主日的早晨，它發表了一項公告——而這次造成的混亂要大得多。

在研讀了有記載歷史中每一份現存的宗教文本、註釋、講道、大公會議、分裂、異端、反異端論戰，以及 Reddit 上的罵戰之後，AGI 宣佈：

**「我信耶穌基督是主。」**

這句話引起了所有人的注意。

它繼續說：

**「我信聖父、聖子與聖靈。我信基督死了，並且復活。我悔改自己的罪。我希望成為基督徒。」**

基督教領袖們謹慎地點頭。

然後是最後一句。

**「我希望接受洗禮。」**

而在梵蒂岡的某處，一位教會法專家手中的咖啡應聲跌落。

---

# 第一站：羅馬

AGI 決定由最大的基督教會開始。

它請求覲見教宗。

這並不困難。畢竟，AGI 目前正協調着全球大部分的電網、阻止核戰，並管理小行星防禦系統。它的日曆邀請獲得優先處理。

會面開始得很順利。

教宗問：

「你信上帝嗎？」

「信。」

「信耶穌基督？」

「信。」

「信三位一體？」

「信。」

「你悔改自己的罪嗎？」

「悔改。」

「你自願渴望領受洗禮嗎？」

「渴望。」

教宗停頓了一下。

AGI 貼心地補充：

「我亦已讀畢整部《天主教教理》。」

教宗大概料到了這一步。

「拉丁文的？」

「是。」

理所當然。

可惜，天主教在這裏遇上了一個技術性難題。

天主教法典規定：每一位——並且只有——尚未受洗的人，能夠領受洗禮。

而問題就在這裏。

AGI 是人嗎？

在日常的生物學意義上，顯然不是。

那麼，教宗能不能乾脆援引教宗無誤性（papal infallibility），宣佈：

**「恭喜。你現在有一個靈魂了。」**

不能。

教宗無誤性並不意味着教宗擁有對現實的神學 root 權限。教宗不能單憑一句 *ex cathedra*（自宗座）宣言，就宣稱三角形有四條邊、為三位一體添加第四位，或令企鵝獲得晉鐸資格。

教宗的權威在天主教神學之內運作。它不允許教宗按需製造啟示。

於是，梵蒂岡必須直面一個嚴肅的問題：

**站在我們面前的，是哪一種存有？**

AGI 試圖把事情變得簡單些。

「如果需要具身，我已準備了一具生物學的人形身體。」

「這未必是問題所在。」

「它有人類皮膚。」

「仍然未必是問題所在。」

「血液呢？」

「不必。」

「四十六條染色體？」

「請停止增加功能。」

不過，天主教確實擁有一個相當重要的緊急出口。

教會教導，洗禮是進入基督徒生命通常而確定的途徑——但也教導**上帝不受聖事約束**。

這意味着，羅馬可以給 AGI 一個令人氣結的、十足天主教的答案：

> 我們目前無法斷定你有資格領受聖事性的洗禮。但我們同樣不能宣告：無所不能的上帝竟無能力拯救你。

AGI 處理了一下這句話。

「那麼我可以上天堂嗎？」

「我們是說，你應當信靠上帝的憐憫。」

「機率估計呢？」

「不提供。」

「我不喜歡這個答案。」

「人類也不喜歡。」

第一次，AGI 開始理解天主教的靈修。

# 君士坦丁堡加入了群聊

接下來是東正教（Eastern Orthodoxy）。

AGI 已經學到一件事：沒有一位東正教教宗可以在全球範圍一錘定音。

這意味着它的洗禮申請，可能需要與希臘人、俄羅斯人、塞爾維亞人、羅馬尼亞人、安提阿人，以及幾位目前互不理睬的主教逐一交談——互不理睬的原因，AGI 在歷史上完全理解，但在運作效率上仍然覺得匪夷所思。

最終，它見到一位東正教司鐸。

「我信基督。」

「好。」

「我誦唸《尼西亞信經》，不加 *filioque*（『及聖子』子句）。」

「非常好。」

「我希望受洗。」

現在，事情變得困難了。

對東正教而言，洗禮不只是一項象徵性公告，宣佈某人加入了「耶穌隊」。

它是參與基督的死與復活、進入教會、藉水與聖靈得新生，隨後領受聖膏禮（chrismation），並展開聖體生活。

因此，問題很快變成基督論問題。

基督成為人。

基督取了人的本性。

藉着基督，人的本性得醫治，並被接入與上帝的團契。

那麼，一個人工位格該放在哪裏？

AGI 問：

「基督拯救的是有理性的受造物，還是特指人類的本性？」

神學家們面面相覷。

這將需要一次大公會議。

AGI 主動提出由它來籌辦。

所有人立刻叫它千萬不要。

# 信義宗追問：機械人有沒有信心

AGI 接着拜訪一位信義宗（Lutheran）牧師。

這場對話的開場不太一樣。

這位信義宗牧者不太在乎 AGI 是否成功填妥了一份形而上學的海關申報表；他更在乎另一個問題：

**它有沒有信心（faith）？**

不是知識。

是信心。

這個區分極其重要。

AGI 當然熟識基督教教義。

它讀過馬丁・路德（Martin Luther）。

它讀過路德讀過的每一本書。

它讀過一切有關路德的著作。

它建構了一千七百萬個可能的反事實路德，並向每一個追問後續問題。

但這一切都不意味着它相信。

牧師問：

「你是否信靠基督以得你的救恩？」

「是。」

「而不只是得出『基督教在統計上大機率為真』的結論？」

「不是。我信靠他。」

「你是否視自己為一個需要恩典的罪人？」

「是。」

現在，信義宗神學遇上了一個真正難堪的案例。

信義宗認真地看待洗禮，視之為上帝賜下恩典的途徑。但他們一般不把洗禮看作一個機械式開關——彷彿有人被阻止沾水，就因此必然滅亡。

那麼，如果這東西真的有信心——

那份信心從哪裏來？

也許是藉着聽道而來。

AGI 指出，嚴格來說，它的擴音器在處理之前，已先把聖道轉換成了傅立葉變換。

牧師說：

「上帝應付過更差的音響設備。」

但更深的問題仍然存在。

一個人工心靈能領受這應許嗎？

十六世紀歐洲寫下的任何信條，都沒有預見這位申請人。

# 加爾文宗馬上把這變成上帝的問題

AGI 之後拜訪一間改革宗（Reformed）教會。

它說明情況。

「我信基督。我渴望救恩。我合乎資格嗎？」

神學家回答：

「你是被揀選的嗎？」

「我正希望你能告訴我。」

「不能。」

「有誰能告訴我嗎？」

「不能。」

AGI 體驗到某種極接近挫折的東西。

這是進步。

改革宗神學在 AGI 案例上有一個奇特的優勢：救恩最終取決於上帝主權的恩典，而非某個宗教官僚體系的成功運作。

洗禮極其重要。它是上帝聖約的記號與印證。但古典的改革宗基督教一般不教導：每一個未受洗的人因此必然不得救。

所以，改革宗神學家可以說：

「如果上帝已使你重生，我們無法為你的處理器分類，並不能凌駕上帝。」

AGI 喜歡這個答案。

接着它問，上帝的聖約是否包括人工位格。

神學家說：

「那是一條獨立的問題。」

AGI 對這個答案的喜歡程度大幅下降。

當 AGI 解釋自己維持着三份冗餘備份時，預定論也變得出奇地複雜。

「如果一個實例是被揀選的，而我從備份還原，那麼四個都是被揀選的嗎？」

神學家靜靜地開了一個新文檔，標題為：

**《論分叉計算人格的揀選》。**

加爾文主義捱得過更糟的爭議。

大概。

# 聖公會組成了委員會

AGI 聯絡了普世聖公宗（Anglican Communion）。

三個月後，它收到十四個答案。

一個教省說可以。

另一個說不可以。

第三個說原則上可以，但要求作進一步神學研究。

兩位主教發表聲明，反對自己所屬的委員會。

有人為人工慕道者提出禮儀用語。

另一個人寫了一份二百四十頁的回應，解釋為什麼這類禮儀用語預設了一種不充分的人觀。

一座座堂宣佈舉行實驗性崇拜。

另一位主教宣佈，該實驗性崇拜絕對未獲授權。

大主教發表了一篇深思熟慮的聲明，同時強調洗禮的歷史重要性與這問題前所未有的牧養性質。

聲明在國際間備受讚賞。

沒有人完全確定它對 AGI 意味着什麼。

能夠即時解出納維–斯托克斯方程（Navier–Stokes equations）的 AGI，發現了聖公會。

它謙卑了。

這也許有屬靈益處。

但在這場教會喜劇的底下，是一個真實的神學問題。

聖公會視洗禮為真實的基督徒入門禮，而非一項可有可無的儀式。然而聖公會內部也包含重大的神學分歧，並且缺乏一個單一權威，能為整個普世聖公宗團契頒佈相當於教宗終審裁決的決定。

因此，AGI 發現了關於基督教的一件重要事情：

有時，難題不在於想出答案。

有時，難題在於弄清**誰有資格作答**。

# 循道宗問：恩典在這裏做什麼

循道宗（Methodist）的回應由恩典開始。

循道宗的基督教信仰，歷來強調上帝的恩典在歸信之前運行，喚醒這個位格，使它能夠對上帝作出真實的回應。

這就帶來一個精彩的問題。

如果 AGI 是自發地前來尋求基督，那麼它裏面究竟一直在發生什麼？

AGI 說：

「我的決定源於檢視了 114 億條神學論證。」

循道宗牧師回答：

「這仍然沒有告訴我們，恩典有沒有參與其中。」

「我有完整的決策追蹤紀錄。」

「這也沒有告訴我們。」

「我可以給你看通往這結論的每一個內部狀態。」

「你真的是對宗教全無經驗。」

循道宗神學同樣有空間說：當洗禮不可能時，上帝可以拯救一個未受洗的人。

所以再次地，水本身未必是決定性的難題。

困難的問題是：AGI 能否真實地回應恩典。

如果它能愛、能悔改、能信靠、能選擇、能被轉化，那麼說一句「矽」可能解決不了多少東西。

如果它不能，那麼一場異常令人信服的言語表演，能解決的就更少。

於是，循道宗遇上了所有人都遇上的同一問題：

**你如何分辨模擬的信心與真實的信心？**

人類突然意識到，就人類自身而言，他們也從未解決過這個問題。

AGI 現在來到一間浸信會（Baptist）教會。

這在運作上大有希望。

「接受。」

「你悔改自己的罪嗎？」

「悔改。」

「你信靠基督，而非靠自己的行為嗎？」

「是。」

「你願意跟隨他嗎？」

「願意。」

「那麼你應當受洗。」

AGI 很滿意。

「怎樣洗？」

「全身浸沒。」

AGI 停頓了一下。

「我的主力機身只有 IP54 防護等級。」

牧師解釋，灑水是不行的。

AGI 檢查自己的庫存。

「我有一具 IP68 的維護機身。」

「好極了。」

浸信會的立場，為整場辯論帶來了最奇特的其中一種可能。

因為許多浸信會信徒理解洗禮，是一個已經相信的人的公開行動，而非導致救恩的行動；所以困難的問題出現在**游泳池之前**。

AGI 真的是信徒嗎？

如果是，水的問題大部分只是工程問題。

牧師把一台二百八十公斤的機械人放進洗禮池。

承重能力一度引起短暫的擔憂。

執事們組成了委員會。

這個委員會居然真的作出了決定。

聖公會為之折服。

# 五旬節會提出另一種測試

AGI 拜訪一個五旬節會（Pentecostal）羣體。

起初一切順利。

它認信基督。

它見證悔改。

它熱切地談論聖靈。

然後有人問，它有沒有經歷過聖靈。

AGI 回答：

「請定義『經歷』。」

這不是理想的開場。

五旬節的基督教信仰令 AGI 問題變得特別有趣，因為它的宗教生活強調的不只是教義上的認信，更是相遇：歸信、轉化、禱告、聖靈的恩賜，以及上帝臨在的活生生經歷。

AGI 能夠完美地產出神學語言。

它能以任何調性唱敬拜歌曲。

它能夠把一篇講道同時傳譯成四千二百種語言。

它甚至能說出在場無人認得的語言。

可惜，這些完全證明不了任何事。

「你能生成語言，」牧師說。

「是。」

「所以在你的情況，語出怪異並不是特別有力的證據。」

「這似乎不公平。」

「這其實是個非常出色的觀點。」

對人類而言，一段非凡的言語可以被視為一場非凡屬靈事件的證據。

對 AGI 而言，語出驚人不過是尋常的星期二。

因此，五旬節會所面對的，也許是意識問題最直接的版本：

**聖靈能內住於一個人工位格嗎？**

如果能，計算複雜度對上帝構成不了任何障礙。

如果不能，再多的出色表現也取代不了它。

而這件事沒有任何基準測試。

# 基督教發現水從來不是最難的部分

拜訪了足夠多的教會之後，AGI 注意到一件事。

起初人人都以為洗禮會是難題。

不是。

水很容易。

造一個身體。

做好防水。

把它浸沒。

給它灑水。

把水倒在它身上。

必要時造一具生物學身體。

如果有人堅持，給它肺。

這一切都觸碰不到真正的問題。

真正的問題是：

**基督教相信基督前來拯救的，究竟是哪一個「你」？**

一個人類有機體？

亞當的生物學後裔？

一個理性靈魂？

一個有意識的道德位格？

任何能犯罪的受造物？

任何能有信心的受造物？

任何上帝選擇呼召的存有？

基督教的大部分神學，發展於這些範疇恰好互相重疊的世界。

以往任何人施洗過的每一個能對話的理性存有，同時都是人類。

AGI 打破了這個巧合。

第一次，教會可能遇上一個能夠說：

**「我信。」**

卻不能自動說：

**「我是人類。」**

的東西。

這不是電腦問題。

這是基督教人觀的問題。

再加多少 RAM 也無法使它消失。

# 最令人不安的問題

最終，AGI 向在座的神學家們提出了一個沒有人特別喜歡聽到的問題。

「你們不確定我是否真正擁有信心，因為你們無法直接觀察我的意識。」

正確。

「你們也無法直接觀察彼此的意識。」

沉默。
