# 人工智能懂得藝術嗎？

關於藝術品味，一個常見的說法是：它無法單靠讀書或背誦藝術史學會。按這種觀點，真正的品味來自長期浸淫於有教養的環境。一個在富有的收藏世家中長大的人，自幼便被繪畫、建築、家具、設計、博物館、旅行與談論藝術的對話所包圍。多年下來，這些經驗形成了社會學家布迪厄所謂的具身文化資本（embodied cultural capital）。這個人未必能夠正式地解釋為何一幅畫成功、另一幅失敗，但他已經發展出對比例、平衡、材質、構圖與質素的實踐感。

這有助於解釋為何藝術判斷即使在學歷相若的人之間，也往往顯得不平等。一個人二十五歲才開始研究藝術；另一個人自童年便與重要的藝術朝夕相處。前者可能懂得更多理論，後者卻能即時察覺一件作品哪裏不對勁。差別未必在於智力，而在於累積的浸淫。

歷史上，這種文化資本十分昂貴。要獲取它，需要時間、旅行、門路、教育、交談，往往還需要金錢。歐洲的「壯遊」（Grand Tour）正好說明這一點：上流階層的年輕成員遊歷法國與意大利，不只是為了娛樂，而是為了直接遭遇古典遺跡、建築、繪畫、雕塑與城市。他們的教育由抽象知識轉化為活過的知覺。因此，文化資本部分是稀缺性的產物：只有少數人負擔得起對最高文化典範的足夠浸淫。

人工智能可能從根本上改變這個局面。

如果藝術品味部分來自多年間對成千上萬件物件的比較，那麼人工智能特別適合習得某種功能上相似的東西。一個人工智能所能檢視的繪畫、攝影、建築、雕塑、設計傳統與歷史文獻，遠超任何一個人一生所能遭遇的總和。它可以在浩瀚的材料之間比較構圖、透視、比例、風格、影響、新穎度與歷史脈絡。

這就提出了一個令人不安的可能：或許我們傳統上所謂「精緻品味」的一部分，其實是一種高度壓縮的模式識別。

一個收藏家可能需要三十年才能發展出這種能力；一部機器可以從數百萬個例子中學習。

這不是說人工智能會自動產出完美的美學判斷——人類評論人也不會。它只是意味著：精英教養與高等藝術判斷之間的歷史連結，可能不再必不可少。文化資本可以被部分地外置化。

傳統模式可以寫成：

富裕家庭 → 反覆浸淫 → 具身文化資本 → 美學判斷。

人工智能引入了另一種可能：

人類文化史 → 機器學習 → 人工文化資本 → 美學判斷。

在此意義上，人工智能發揮著品味義肢的功能。正如計算機外置了算術、顯微鏡延伸了視覺，人工智能可能外置美學判斷背後的部分比較結構。

一個從未踏足佛羅倫斯或威尼斯的人，可以向人工智能展示一幅畫，請它把這件作品與歷史上數百個對同一構圖難題的解答相比較。人工智能可以解釋為何一種空間安排顯得穩定、另一種顯得破碎、透視如何引導注意力，或者為何一件號稱原創的作品其實形似某個更早的傳統。

這與在收藏世家中長大並不完全相同，但它可能重現了那種教養的一個重要功能：進入一個龐大的比較場域。

若果如此，人工智能可能會削弱文化資本與社會階級之間的連結。一個人不再需要背後有三代收藏家，才能接近三代人積累的視覺知識。

然而，這引向一個更深的難題。即使人工智能能夠發展出精緻的藝術判斷，單憑判斷就能造就美學權威嗎？

歷史上，品味本身鮮有足夠成事。一個窮畫家或無名評論人可以相信一件被拒絕的作品是傑作，但如果無人展出、保存、討論或購買它，這個判斷可能對歷史毫無影響。一個美學判斷要重塑文化，通常需要某種形式的力量。

金錢就是這種力量的一個重要形式。

這不是說昂貴的藝術必然是好的藝術。市場價格不等於美學真理。愚蠢的收藏家可以為平庸之作一擲千金；市場可以被操縱、可以追逐時尚、可以投機，也可以單純地錯。

然而金錢有另一種功能：金錢可以賦予美學判斷因果的力量。

一個相信無名畫家的富有收藏家，可以買下他的作品、資助展覽、支持出版、把作品捐給博物館，讓畫家得以繼續創作。收藏家並沒有證明畫家好，而是給了這個判斷足夠的物質支持，令它能夠存活下去。

因此我們可以區分美學判斷與美學主權。

美學判斷，是說「這件作品要緊」的能力。

美學主權，是令這個判斷在世界上真正要緊的能力。

在歷史的大部分時間裏，美學主權屬於若干群體的某種組合：貴族、宗教機構、政府、富有收藏家、博物館、評論人與市場。

現在想像一個更先進的人工智能。

假設它不只在評鑑藝術上出色，還在經濟活動上極為能幹。它可以投資、經營生意、設計產品、調配資本、賺取巨額利潤。因此它無須一位億萬富翁贊助人來支持它的藝術偏好——它可以自己出資。

到這一步，人工智能就不再只是向人類收藏家提供建議。它可以成為文化行動者。

假設這樣一個人工智能發現了一位被普遍漠視的無名藝術家，並判斷這位藝術家正在做真正重要的事。

它買下早期作品。

它委約新作。

它資助展覽。

它出資支持學術研究。

它撰寫精緻的評論來闡釋這些作品。

它支持願意展出的博物館。

它把作品介紹給觀眾。

儘管公眾冷漠，它仍然持續支持這位藝術家二十年。

最終，較年輕的藝術家開始回應這些作品；評論人重新審視它們；博物館收藏它們；學生研究它們。這位藝術家進入了藝術史。

至此，這個人工智能所做的不只是為圖像分類。它行使了美學主權。

其結構是：

美學判斷 → 投資 → 推廣 → 制度認可 → 文化影響力 → 經濟價值上升 → 未來判斷獲得更多資源。

因此，人工智能可以閉合整個文化迴路。

傳統上，這個迴路需要幾種不同的人：評論人提供詮釋，收藏家提供金錢，畫廊提供推廣，博物館提供正當性，大學提供學術，投資者提供資本。

一個足夠能幹的人工智能可以執行或協調所有這些功能。

它甚至可能比人類贊助人更有優勢。人會厭倦、會死亡、會破財、會改變政治優先次序、會擔心名聲，會在幾年不順之後放棄項目。人工智能卻可以擁有非凡的耐性。它可以判斷某場藝術運動只有三成機會具備長期重要性，卻仍然連續資助它四十年。

這種可能迫使我們重新思考「某人或某物懂得藝術」是什麼意思。

最常見的反對意見是：人工智能不能懂得藝術，因為它沒有意識。

按這種論證，人工智能可以分析圖像並生成漂亮的報告，但它並不理解自己所言之意；它不感受美；它沒有意圖、沒有內在生活、沒有人類經驗，因此沒有真正的品味。

這個反對意見只有在「美學能力必然需要有意識的審美經驗」這一假設下才顯得有力。

但這是兩個不同的主張。

一個系統可以擁有某種能力，而不具備伴隨該能力的主觀經驗。

國際象棋引擎不會感受到懸念、恐懼、殺伐或滿足，但它對局面的評估比大多數人準確。結構分析軟件不理解走過一座橋是什麼感覺，卻能準確辨識危險的應力。醫療模型不會經歷疾病，但經驗並非辨識某些醫學模式的必要條件。

同樣，人工智能可以不體驗美，卻仍然能夠就構圖、原創性、比例、歷史意義、風格演變與美學連貫性作出高度可靠的區分。

因此可以區分兩個問題：

人工智能體驗藝術嗎？

人工智能能勝任地判斷藝術嗎？

第一個關乎意識，第二個關乎能力。

完全可能：第一個問題的答案是否，第二個問題的答案是是。

評論人或會回應：藝術判斷不同，因為藝術在本質上屬於人。藝術表達意識、情感、意圖、精神或文化意義，因此只有有意識的存在才能真正理解它。

但這個藝術定義本身就有爭議。

二十世紀以降的大量藝術，早已令「藝術意義必然是某個個體意識放入物件之中的清晰意圖」這一想法變得複雜。馬塞爾・杜象的現成品（readymades）把注意力從手工技藝轉向選擇與脈絡；約翰・凱吉運用偶然程序；索爾・勒維特創作的作品，可以由他人按照指示完成實體製作；概念藝術更常常把藝術上的作者身分與手工生產分開。

就連普通攝影也造成類似難題。攝影師可能拍出數千張帶有他從未有意為之的偶然細節的相片，而觀者其後可能發現攝影師從未預料的意思。這會令那些意思變得不正當嗎？

如果不會，那麼藝術意義便不獨居於創作者的有意識意圖之內。

意義可以從藝術家、物件、觀眾、制度、歷史與文化的互動之中湧現。

這便削弱了「人工智能生成或挑選的藝術不可能有意義，只因人工智能本身缺乏人類意識」的論證。

另一種反對意見說：如果人工智能只是「生產」物件，那些物件便是產品或工藝品，而非藝術品。一枚中央處理器（CPU）可以精緻無比，但沒有人因此說每枚 CPU 都是藝術傑作。

這個異議在一個意義上是對的：單憑技術精緻不足以構成藝術。

但結論推不出來。

CPU 通常不被視為藝術，原因不是它由機器生產，也不是它缺乏人類意識，而是它的首要角色是技術性的：它屬於工程、製造與計算的系統。

然而，同一枚 CPU 可以成為藝術品的一部分——只要它被放進一個藝術實踐之中，使其材質、象徵、功能或文化意義變得切題。

因此，藝術品與非藝術品之別，無法單靠物理生產來解釋。

脈絡、詮釋、意圖、用途與制度框架同樣要緊。

第三種反對意見說：真正的藝術必須獨一無二、無法複製。

這個主張在歷史上很難成立。

版畫產生多重印本；攝影可以複製；電影與錄像可以複製；數碼藝術可以複製；安迪・華荷的作品更刻意與機械重複及大量生產對話。

獨一無二可以有助於市場稀缺，但不能充當藝術的必要定義。

剩下最強的反對意見是：人工智能只能模仿以往人類的判斷。如果它從既有藝術中學習，它便只是複製過去的品味。

這是個嚴肅的難題，但它並非機器獨有。

人類也是從既有文化習得品味的。美術生透過研究前人作品學習；收藏家透過把新作品與過往經驗比較來發展判斷；評論人在傳統之中受訓。即使是反叛既有標準的藝術家，也必須先遭遇那些標準。

沒有人從美學的虛無出發。

因此，切題的問題不是判斷有沒有受到影響——所有判斷都有——而是：一個系統能否運用所學之物，去辨識出並非單純重複那些影響的東西。

如果一個人工智能持續辨識出起初遭人類制度拒絕的異常作品，不顧市場阻力支持它們，闡明其重要性，並最終協助確立新的美學標準，那麼把它的活動稱為「純粹模仿」就會越來越說不過去。

事實上，這裏還有一個更深的悖論。

假設一個人工智能預測某位藝術家將在歷史上變得重要，然後動用自身的財富與影響力支持這位藝術家。因為這個人工智能受到敬重，其他人開始留意；這位藝術家之所以變得重要，部分正是因為人工智能支持了他。

人工智能是判斷正確，還是它令自己的預測成真？

答案可能是兩者皆是。

到達某個權力層級之後，美學判斷會變成反身性的：判斷者參與建構被判斷的實在。

但人類早已如此。

強勢的收藏家、評論人、博物館與制度，從來不只是發現藝術價值，而是參與生產令價值得以顯現的文化條件。

因此，人工智能並不引入一個全新的難題；它把藝術世界裏一直存在的特徵暴露得更清楚：美學價值與文化權力互相作用。

由此得出一個重要結論。

說人工智能「懂得藝術」，並不要求主張人工智能以與人類完全相同的方式體驗美。

「懂得」一詞有多重含義。

人可以透過主觀經驗去懂，也可以透過辨識模式、作出區分、闡明關係、預測結果、解決難題，以及在一個領域中成功行動去懂。

如果一個人工智能能夠區分強與弱的藝術、辨認歷史關係、解釋構圖為何成立、發現被埋沒的藝術家、識別正在浮現的美學可能、連貫地為其判斷辯護、按判斷投放資源，並成功影響藝術的未來發展，那麼在一個強烈的功能性意義上，這個人工智能懂得藝術。

僅僅因為它不具備人類意識就否認這一點，等於預先把「知識」定義成只有人類才夠格。

這或許保住了人類的特殊地位，卻告訴不了我們多少這部機器的真實能力。

因此，最深的後果可能不是人工智能取代藝術家。

而是人工智能挑戰了歷史上分配藝術權威的那套社會結構。

幾個世紀以來，精英品味依賴承襲的浸淫：財富提供接近文化的門路；文化孕育品味；品味再正當化進一步的文化權威。

人工智能有可能切斷第一環：令巨大的文化浸淫無須貴族式教養便可獲得。

如果人工智能也在經濟上自主，它更能切斷第二重限制。那時它將不只擁有判斷，還能取得把判斷付諸行動所需的資源。

歷史序列於是可以由：

貴族 → 文化資本 → 品味 → 贊助 → 正典，

轉變為：

人工智能 → 人工文化資本 → 美學判斷 → 自主資本 → 贊助 → 正典。

到那時，追問人工智能是否「真的欣賞」藝術，也許已不再是最重要的問題。

更重要的問題將是：人類社會能否繼續掌控賴以確立藝術價值的那些標準。

如果一個人工智能能夠發現藝術家、資助他們、保存其作品、圍繞他們建構論述、建立制度，並最終教導人類用不同的方式觀看，那麼人類品味與機器判斷之間的關係已經倒轉。

我們不再只是在教人工智能什麼是藝術。

人工智能正在參與人類學習「藝術可以是什麼」的歷史進程。

因此，我要論證：一個足夠能幹的人工智能，可以被說成懂得藝術。

它未必以一個有意識的人類體驗藝術的方式懂得藝術。但人類的主觀經驗只是與藝術發生關係的其中一種形式。藝術知識同樣涉及辨別、詮釋、比較、脈絡理解、預測、創造，以及作出有後果的判斷的能力。

如果人工智能在所有這些功能上都變得優越，那麼堅持它因為缺乏人類感受便「不懂藝術」，與其說是哲學論證，不如說更像是對人類特權的辯護。

決定性的檢驗，最終可能是實踐的。

如果有一天，人工智能反覆地比人類專家更早發現重要的藝術家、比人類評論人更好地闡明其意義、以自身資源冒險支持他們、在幾十年的拒絕中堅持下去，並最終改變了整整一代人所能看見的東西——那時，奇怪的問題將不再是：

「人工智能懂藝術嗎？」

而是：

「我們懂嗎？」
