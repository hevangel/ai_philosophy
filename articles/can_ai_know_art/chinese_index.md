# 人工智能懂得藝術嗎？

關於藝術品味，一個常見的說法是：它無法單靠讀書或背誦藝術史來傳授。按這種觀點，真正的品味來自長期浸淫於一個有教養的環境。在富有的收藏世家中長大的人，可能自幼便被繪畫、建築、家具、設計、博物館、旅行，以及談論藝術的對話所包圍。多年下來，這些經驗形成了社會學家皮埃爾·布迪厄(Pierre Bourdieu)所謂的具身文化資本(embodied cultural capital)。這個人未必能夠正式解釋為何一幅畫成功、另一幅失敗，但他已發展出對比例、平衡、材質、構圖與質素的實踐感。

這有助於解釋，為何即使在受教育程度相若的人之間，藝術判斷也往往顯得不平等。一個人二十五歲才開始研習藝術；另一個人自童年起便與重要的藝術朝夕相處。前者可能懂得更多理論，後者卻能即時察覺一件作品哪裏不對勁。分別未必在於智力，而在於累積的浸淫。

在歷史上，這種文化資本十分昂貴。要獲得它，需要時間、旅行、門路、教育、交談，還往往需要金錢。歐洲的「壯遊」(Grand Tour)正好說明這一點：上流階層的年輕成員遊歷法國與意大利，不只是為了娛樂，更是為了親身接觸古典遺跡、建築、繪畫、雕塑與城市。他們所受的教育由抽象知識轉化為活過的知覺。因此，文化資本部分是稀缺的產物：只有少數人負擔得起足夠的浸淫，去接觸文化中最高的範例。

人工智能可能會從根本上改變這個局面。

如果藝術品味部分來自多年間對成千上萬件物件的比較，那麼人工智能便特別適合習得某種在功能上相似的東西。一個人工智能所能檢視的繪畫、攝影、建築、雕塑、設計傳統與歷史文獻，遠超任何一個人一生所能接觸的總和。它可以在極大量的材料之間，比較構圖、透視、比例、風格、影響、新意與歷史脈絡。

這就提出了一個令人不安的可能：或許我們傳統上稱為「精緻品味」的東西，有一部分是一種高度壓縮的模式識別。

一個收藏家可能需要三十年才能發展出這種能力；一部機器卻可以從數百萬個例子中學習。

這不是說人工智能會自動作出完美的美學判斷——人類評論人也不會。它只意味着：精英教養與高超藝術判斷之間的歷史連繫，可能已不再必要。文化資本可以部分地被外化。

傳統模式可以寫成：

富裕家庭 → 反覆浸淫 → 具身文化資本 → 美學判斷。

人工智能引入了另一種可能：

人類文化史 → 機器學習 → 人工文化資本 → 美學判斷。

在此意義上，人工智能發揮着品味義肢的功能。正如計算機把算術外化、顯微鏡延伸視覺，人工智能也可能把美學判斷背後的部分比較結構外化。

一個從未踏足佛羅倫斯或威尼斯的人，可以向人工智能展示一幅畫，請它把這件作品與歷史上數百個針對同一構圖難題的解答相比較。人工智能可以解釋為何某一種空間安排顯得穩定、另一種顯得破碎、透視如何引導注意力，或者為何一件據稱原創的作品其實近似某個更早的傳統。

這與在收藏世家長大並不相同，但它可能重現那種教養的一項重要功能：進入一個龐大的比較場域。

若然如此，人工智能便可能削弱文化資本與社會階級之間的連繫。一個人不再需要背後有三代收藏家，才能取得三代人的視覺知識。

然而，這引向一個更深的問題。即使人工智能能發展出精深的藝術判斷，單憑判斷就能造就美學權威嗎？

在歷史上，單憑品味本身鮮能成事。一個窮困的藝術家或無名的評論人可以相信一件遭拒的作品極為出色，但如果無人展出它、保存它、討論它或購買它，這個判斷可能對歷史影響甚微。一個美學判斷要重塑文化，通常需要某種形式的權力。

金錢是這種權力的一個重要形式。

這不是說昂貴的藝術必然是好藝術。市場價格與美學真理是兩回事。愚昧的收藏家可以為平庸之作一擲千金；市場可以被操縱、可以追逐時尚、可以充斥投機，也可以純粹是錯的。

然而金錢另有一種功能。金錢能賦予美學判斷因果力量。

一個相信某位無名藝術家的富有收藏家，可以買下他的作品、資助展覽、支持出版、把作品捐給博物館，讓藝術家得以繼續創作。收藏家並沒有證明這位藝術家是好的；他只是給予這個判斷足夠的物質支持，使它能夠存活。

因此，我們可以區分美學判斷與美學主權(aesthetic sovereignty)。

美學判斷，是說「這件作品要緊」的能力。

美學主權，是令這個判斷在世界上真正要緊的能力。

在歷史的大部分時間裏，美學主權屬於貴族、宗教機構、政府、富有的收藏家、博物館、評論人與市場的某種組合。

現在想像一個更先進的人工智能。

假設這個人工智能不只在評估藝術上出色；再假設它在經濟活動上也極為能幹。它可以投資、經營生意、設計產品、調配資本、賺取巨額利潤。因此，它不需要一位億萬富翁贊助人來支持其藝術偏好——它可以自己出資。

到了這一步，人工智能便不再只是向人類收藏家提供建議。它可以成為一個文化行動者。

假設這樣的一個人工智能發現了一位作品廣受漠視的無名藝術家，並判斷這位藝術家正在做真正重要的事。

它買下早期作品。

它委約新作。

它資助展覽。

它出資支持學術研究。

它撰寫精深的評論來闡釋這些作品。

它支持願意展出的博物館。

它把作品介紹給觀眾。

儘管公眾冷漠，它仍持續支持這位藝術家二十年。

最終，較年輕的藝術家開始回應這些作品；評論人重新審視它；博物館收藏它；學生研究它。這位藝術家進入了藝術史。

至此，這個人工智能所做的已不止於為圖像分類。它行使了美學主權。

其結構是：

美學判斷 → 投資 → 推廣 → 制度認可 → 文化影響力 → 經濟價值上升 → 未來判斷獲得更多資源。

因此，這個人工智能可以閉合整個文化循環。

傳統上，這個循環需要幾種不同的人：評論人提供詮釋，收藏家提供金錢，畫廊提供推廣，博物館提供正當性，大學提供學術研究，投資者提供資本。

一個能力足夠的人工智能，可以執行或協調所有這些功能。

它甚至可能比人類贊助人更有優勢。人會厭倦、會死亡、會損失金錢、會改變政治上的優先次序、會顧慮名聲，或在幾年沒有成績之後放棄計劃。人工智能卻可以擁有非凡的耐性。它可以判斷某個藝術運動只有三成機會具有長遠重要性，卻仍然連續四十年資助它。

這種可能性迫使我們重新思考：說某人或某物「懂得藝術」，究竟是什麼意思。

最常見的反對意見是：人工智能不能懂得藝術，因為人工智能沒有意識。

按這套論證，人工智能可以分析一幅圖像，生成一份令人印象深刻的報告，但它並不理解自己言辭的意義。它感受不到美。它沒有意圖、沒有內在生活、也沒有人類經驗，因此它沒有真正的品味。

只有在我們假定審美能力必須依賴有意識的審美經驗時，這個反對意見才顯得有力。

但這是兩個不同的主張。

一個系統可以擁有某種能力，而不必具備伴隨該能力而來的主觀經驗。

國際象棋引擎不會感受到懸念、恐懼、攻擊性或滿足，但它評估局面比大多數人類更準確。結構分析軟件不明白走過一條橋是什麼感覺，卻能準確辨識危險的應力。醫療模型不會經歷疾病，但經驗並非辨識某些醫學模式的必要條件。

同樣，人工智能可以不體驗美，卻仍然能夠就構圖、原創性、比例、歷史意義、風格發展與美學連貫性，作出高度可靠的區分。

因此可以區分兩個問題：

人工智能體驗藝術嗎？

人工智能能夠稱職地判斷藝術嗎？

第一個問題關乎意識，第二個關乎能力。

完全有可能：第一個問題的答案是否定的，而第二個問題的答案是肯定的。

評論人或會回應：藝術判斷有所不同，因為藝術在本質上是屬於人的。藝術表達意識、情感、意圖、精神或文化意義，因此只有有意識的存在者才能真正理解它。

但這個藝術定義本身就有爭議。

二十世紀以至當代的許多藝術，早已令「藝術意義必然在於某個個體意識放進物件裏的清晰意圖」這一想法變得複雜。馬塞爾·杜象(Marcel Duchamp)的現成品(readymades)把注意力從手工技藝轉移到選擇與脈絡；約翰·凱吉(John Cage)運用機遇程序；索爾·勒維特(Sol LeWitt)創作了可以由他人按照指示完成實體製作的作品；概念藝術更常常把藝術上的作者身分與手工生產分開。

就連普通的攝影也造成類似的問題。攝影師可能拍出數千張相片，當中包含他從未刻意為之的偶然細節；觀者其後可能發現攝影師從未預料到的意義。這會令這些意義變得不正當嗎？

如果不會，那麼藝術意義便不只居於創作者的有意識意圖之內。

意義可以從藝術家、物件、觀眾、制度、歷史與文化的互動之中湧現。

這便削弱了這樣的論證：人工智能生成或挑選的藝術，僅因人工智能本身缺乏人類意識，便不可能有意義。

另一種反對意見說：如果人工智能只是「生產」物件，這些物件便是產品或工藝品，而非藝術品。一枚中央處理器(CPU)可以精妙無比，但沒有人因此下結論，說每枚 CPU 都是藝術傑作。

這個異議在一點上是對的：單憑技術上的精妙，不足以令一件事物成為藝術。

但結論推不出來。

CPU 通常不被視為藝術，原因並不僅僅在於它由機器生產，或者在於它缺乏人類意識。它的首要角色是技術性的，屬於工程、製造與運算的系統。

然而，同一枚 CPU 若被置於一個藝術實踐之中，令它的材質、象徵、功能或文化意義變得切題，也可以成為藝術品的一部分。

因此，藝術品與非藝術品之別，無法單靠物理生產來解釋。

脈絡、詮釋、意圖、用途與制度框架同樣要緊。

第三種反對意見說：真正的藝術必須獨一無二、無法複製。

這個主張在歷史上很難站得住腳。

版畫產生多個印本。攝影可以複製。電影與錄像可以複製。數碼藝術可以複製。安迪·華荷(Andy Warhol)的作品更刻意回應機械重複與大量生產。

獨一無二也許有助於市場稀缺，但不能充當藝術的必要定義。

剩下最強的反對意見是：人工智能只能模仿以往人類的判斷。如果它從既有藝術中學習，它便只是複製過去的品味。

這是個嚴肅的問題，但它並非機器獨有。

人類的品味同樣是從既有文化中習得的。學藝術的學生透過研習前人的藝術來學習；收藏家透過把新作品與過往經驗比較來發展判斷；評論人在傳統之中受訓。即使是反叛既有標準的藝術家，也必須先接觸那些標準。

沒有人是從美學的虛無出發的。

因此，相干的問題並非判斷有沒有受到影響。所有判斷都受影響。

問題在於：一個系統能否運用所學，辨識出某種並非單純重複那些影響的東西。

如果一個人工智能持續辨識出起初遭人類制度拒絕的不尋常作品，不顧市場阻力支持它們，闡明其重要性，並最終協助確立新的美學標準，那麼把它的活動稱為「純粹模仿」就越來越說不過去。

事實上，這裏還有一個更深的悖論。

假設一個人工智能預測某位藝術家將在歷史上變得重要，然後運用自身的財富與影響力去支持這位藝術家。由於這個人工智能受到敬重，其他人開始留意。這位藝術家之所以變得重要，部分正是因為人工智能支持了他。

人工智能究竟是判斷正確，還是令自己的預測成真？

答案可能是兩者皆是。

到了某一權力水平，美學判斷便變得具有反身性。判斷者協助建構正被判斷的實在。

但人類早已如此。

強勢的收藏家、評論人、博物館與各種制度，並不只是發現藝術價值；它們參與生產令價值得以顯現的文化條件。

因此，人工智能並不會引入一個全新的問題；它只是把藝術世界向來存在的特徵暴露得更清楚：美學價值與文化權力相互作用。

由此得出一個重要結論。

說人工智能「懂得藝術」，並不要求主張人工智能以與人類完全相同的方式體驗美。

「懂得」一詞有多重含義。

人可以透過主觀經驗而懂，也可以透過辨識模式、作出區分、闡明關係、預測結果、解決問題，以及在一個領域之內成功行事而懂。

如果一個人工智能能夠區分強的藝術與弱的藝術、辨認歷史關係、解釋構圖為何行得通、發現被忽視的藝術家、識別正在浮現的美學可能性、連貫地為自己的判斷辯護、按這些判斷投放資源，並成功影響藝術的未來發展，那麼在一個強烈的功能意義上，這個人工智能懂得藝術。

僅僅因為人工智能不具備人類意識就否認這一點，等於預先把「知識」定義成只有人類才合資格。

這或許保住了人類的特殊地位，卻無助於我們了解這部機器的實際能力。

因此，最深的後果可能不是人工智能取代藝術家。

而可能是人工智能挑戰了歷來分配藝術權威的那套社會結構。

幾個世紀以來，精英品味都依賴承襲的浸淫：財富提供接觸文化的門徑；文化孕育品味；品味又正當化進一步的文化權威。

人工智能有可能打破第一重連繫：令巨大的文化浸淫無須貴族式教養也能獲得。

如果人工智能在經濟上也變得自主，它同樣能打破第二重限制。它將不只是擁有判斷。它能夠取得把判斷付諸實行所需的資源。

歷史序列於是可以由：

貴族 → 文化資本 → 品味 → 贊助 → 經典

轉變為：

人工智能 → 人工文化資本 → 美學判斷 → 自主資本 → 贊助 → 經典。

到那時，追問人工智能是否真的「鑑賞」藝術，也許已不再是最重要的問題。

更重要的問題將是：人類社會能否繼續掌控賴以確立藝術價值的那些標準。

如果一個人工智能能夠發現藝術家、資助他們、保存其作品、圍繞他們建構論證、建立制度，並最終教導人類以不同的方式觀看，那麼人類品味與機器判斷之間的關係，便已倒轉。

我們將不再只是教人工智能什麼是藝術。

人工智能將參與人類學習「藝術可以是什麼」的歷史進程。

因此，我會論證：一個能力足夠的人工智能，可以說是懂得藝術的。

它未必以一個有意識的人類體驗藝術的方式去懂得藝術。但人類的主觀經驗只是與藝術發生關係的形式之一；藝術知識還涉及辨別、詮釋、比較、脈絡理解、預測、創造，以及作出具有後果的判斷的能力。

如果人工智能在所有這些功能上都變得更優勝，那麼堅持它因為缺乏人類感受便不「懂得藝術」，與其說是哲學論證，恐怕不如說是對人類特權的辯護。

決定性的檢驗，最終可能是實踐性的。

如果有一天，一個人工智能反覆比人類專家更早發現重要的藝術家，比人類評論人更好地闡明其意義，以自身資源在他們身上冒險，在數十年的拒絕之中持續支持他們，並最終改變整整一代人所能看見的東西——那麼，奇怪的問題也許將不再是：

「人工智能理解藝術嗎？」

而會是：

「我們理解嗎？」
