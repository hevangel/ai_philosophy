# 生物學中的「功能」是什麼？

摘要：本文將論證，根據為生物功能理論選定的若干重要必要條件（desiderata），普賴爾（Prior）的功能分析學說是生物學功能理論中最有希望的一套。我將接着在「目的論說明的初步難題」上，為普賴爾的觀點抵擋尼安德爾（Neander）的攻擊。

在課程的後半部，我們考察了許多生物學功能理論的學說：[1] 與 [2] 研究了幾種已被拒斥的古典功能理論、賴特（Wright）[1] 提出的標準病因論（etiological）進路、康明斯（Cummins）[2] 提出的系統進路、布爾斯（Boorse）[3] 提出的目標導向進路、比奇洛（Bigelow）[4] 提出的前瞻進路，以及普賴爾 [6] 提出的功能分析進路。尼安德爾的文章沒有提出新方案，而是加固賴特的論證；戈弗雷-史密斯（Godfrey-Smith）的文章則掃了大家的興：他提出這場辯論的兩大陣營——分別以賴特與康明斯為首——談論的其實是兩種不同的功能觀念。在所有功能理論之中，我認為普賴爾那套以修訂版康明斯進路為基礎的學說，最有希望解釋生物學中的功能是什麼。我先彙集各篇文章的功能判準，概述生物功能理論的必要條件。

一套可接受的功能理論必須區分功能與單純的效應。例如，心臟的功能是泵血；它的功能不是發出撲通聲。這個例子賴特與康明斯都用過，差不多是任何功能理論最基本的石蕊測試。

一套可接受的功能理論必須同時解釋人工的（有意識的）與自然的（生物的）功能。其實在我看來，丟棄這條判準便會打開生物功能理論的所有限制：如果我們可以把人工功能與自然功能當作兩個可區分、互不相交的類別，功能理論中的大部分論證便會自動消失。生物功能將變得像物理功能、化學功能一樣，只是對因果效應與事物如其所然地發生的描述性說明。然而賴特、康明斯以及幾乎所有其他人都選擇保留這條判準，為了令本文前提與所有論文一致，我只好把它包括進來。

一套可接受的功能理論必須區分功能與功能失常（malfunction）、無功能、退化器官（vestige）、統計上正常的功能、意外與非預期功能。這條判準正是各家功能理論互相分歧之處；換言之，這是激戰的主戰場。康明斯陣營攻擊賴特陣營：病因論進路對上述任何一種區分——乃至全部——都無法處理；賴特陣營則反駁說他們的學說應付得了。我觀察到的問題是：「功能」的實際意義似乎被各陣營為遷就自己的理論而這樣那樣地扭歪了。在此我為每種區分提出一個石蕊測試，令判準保持簡單。一顆無法泵血的心臟——例如因某種基因缺陷，天生缺少一片瓣膜——是功能失常的心臟。盲腸是人體中無功能、退化的器官。如果一種病毒令 99% 的人口失明，眼睛的功能仍然是看。皮帶扣的功能不是擋子彈，雖然意外有時真的發生，它真的擋住了子彈、救了一命。普賴爾假想的「葡萄蝦兩用剝殼器」，其功能是為蝦剝殼。我們也可以用一個現實例子替代葡萄蝦剝殼器：雷射被發明時，本意是用作雷射武器，結果發現雷射用來讀取 DVD 資料也非常有用。

一套可接受的功能理論必須把超級功能納入考量。超級功能的一個例子：一般而言，眼睛的功能是看；但在漫畫《X戰警》中，變種人超級英雄獨眼龍（Cyclops）能從眼睛射出雷射，因此他的眼睛既有看的功能，也有射雷射的功能。然而我們並不知道從眼中射出雷射是否有任何演化優勢，甚至不知道這是否可遺傳的性狀——漫畫沒有提到他有任何後代，而身為變種人這一事實本身便令他時刻身陷險境。

下一節我將概述普賴爾的功能理論，並與賴特的病因論對照，按上述必要條件檢視兩套理論。

普賴爾把功能陳述定義為功能分析的輸出：「按此學說，功能的歸屬既是相對於理論，也是相對於興趣——某器官的功能，是其諸效應之中，在我們對該生物體某個有趣（更高層級）能力的最佳說明中佔一席者。」[6] 他又說，其學說與康明斯的功能分析相似：「訴諸功能，是為了解釋功能所屬系統的能力，而非為了解釋功能所歸屬之項目的存在。」[6] 相反，賴特的病因論學說主張：「『X 的功能是 Z』意謂：(a) X 之存在是因為它做 Z；(b) Z 是 X 存在的後果（或結果）。」[1] 簡言之，普賴爾的理論不關心器官如何到位，只關心器官與生物體之間、或生物體與生態系統之間的效應與關係；賴特的理論則要求功能解釋器官如何到位。

普賴爾與賴特的理論都輕易通過第一條判準，儘管解釋各異。在普賴爾的學說中，他可以循康明斯的思路，在血液循環系統的脈絡下解釋心臟的功能：由於在解釋循環系統的能力時，泵血——而非發出心跳聲——是心臟在系統中被需要的效應，我們便能區分心臟的功能是泵血，而發出噪音只是單純的效應。賴特則會這樣解釋：心臟泵血賦予物種演化優勢，提升該物種中擁有這種基因型的族群的生存適應度，因此泵血的心臟存在，因為那正是被選中的東西。心跳聲不帶來任何演化優勢，它是被順帶挑上的（selected of）——一個搭着心臟泵血功能順車遺傳下來的性狀。既然第一條判準是任何功能理論最基本的要求，兩套理論都能解釋得好，並不令人意外。

第二條判準沒有多少爭議，因為普賴爾與賴特都刻意令其理論與人工選擇相容。普賴爾的進路其實源於人工功能的功能學說，再擴展至自然功能。機械部件的功能由其在機械系統中的設計意圖決定。在達爾文之前、神創論主宰自然研究的年代，自然功能與人工功能幾乎共用同一套說明，唯一差別是：人工功能的有意識行動者是人，自然功能的有意識行動者是上帝。中世紀的醫生便以生理功能解釋生物功能——生理功能正是對整個身體執行功能分析程序的結果。然而這套說明並非沒有難題：按定義，無人知道上帝的真正意圖，所謂自然功能其實只立於人們對上帝意圖的猜測、或宗教權威對「知道上帝意圖」的宣稱之上。如果意圖不可知或猜錯了，功能便可能完全錯誤。歷史上很長一段時間，人們以為產生情感也是心臟的功能之一——按現代科學之光來看，這明顯是錯的。賴特的進路恰恰相反：他把自然選擇替換為設計者或使用者的選擇，把自然功能的生物學說明擴展至涵蓋人工功能。就此而言，這其實簡化了病因論的難題。病因論最大的難題是立於自然選擇理論之上，而我們在前面的課中已看到自然選擇理論本身頗有疑點。以源自有意識行動者的人工選擇取代自然選擇，消除了方程式中的不確定性：若有任何疑問，我們總可以問行動者的選擇標準是什麼。

普賴爾的理論對第三條判準沒有多大困難。一旦透過在系統及其能力的脈絡中執行功能分析而識別出標稱功能（nominal function），任何偏離標稱功能的情況都可視為功能失常、無功能或意外。如果系統改變、標稱功能不再被需要，它便成為退化器官。如果相對於更高層級系統，系統與能力的脈絡被正確識別，我們便可推知功能的意圖，並分辨統計上正常的功能與標稱功能之別。至於非預期功能，只要更新系統的脈絡與能力再跑一次功能分析便可處理。賴特的學說回答第三條判準的問題就吃力一些。功能失常與無功能可以在殊例與類型的關係中理解：殊例偏離類型、且偏離降低適應度者，可視為功能失常或無功能。退化器官最易處理，因為病因論保留着功能的歷史記錄。統計上正常的功能用回望式學說處理稍難，但如果以比奇洛 [4] 的前瞻學說為病因論打補丁，我們仍能區分功能與統計上正常的功能：例如，令 99% 人口失明的病毒並不會改變眼睛的功能，因為能看見的眼睛仍然擁有演化優勢。在病因論中，如果一個功能不是遺傳而來，我們可以把它當作意外而非功能。回望式學說無法處理非預期功能，前瞻式學說卻沒有難題——只要擁有選擇優勢，非預期功能仍然是功能。

我相信第四條判準真正令兩套理論分出高下。按漫畫設定，獨眼龍的雷射眼來自第一代基因突變。顯然，回望式病因論找不到任何先前的選擇歷史可供賴特使用。長一雙雷射眼並不令他對女性更有吸引力，因此不帶來任何繁殖優勢。在 X戰警的世界裏，政府追捕變種人、邪惡變種人為統治世界向正義變種人開戰、正義變種人不時還要保衛地球免受外星人入侵——變種人的存活能力看起來比普通人更差。如果沒有前瞻的選擇優勢，我們也無法使用比奇洛的前瞻病因論。然而，說「射雷射不是獨眼龍眼睛的功能」會很奇怪，因為那正是他的眼睛實實在在做的事。普賴爾的學說沒有這個難題：我們可以把獨眼龍當作變種人——一個有別於普通人的系統——輕易地對他的眼睛執行功能分析，得出它們具有看東西與射雷射的功能。這正是中世紀醫生判定人體部位功能的方法，也正是 51 區的《X檔案》科學家解剖外星人時判定外星器官功能的方法。

在尼安德爾的文章 [5] 中，她以不同策略攻擊康明斯的學說：她動用的是針對一切目的論說明的初步（prima facie）一般難題——目的論說明以目的解釋手段：一個發展或性狀，透過訴諸目標、目的或功能來解釋。目的論說明訴諸效應，但目的、目標與功能性效應往往從未實現。就人工功能而言，目的論說明訴諸的也不是功能的實際效應，而是行動者的意圖效應。當目的落空，行動者仍然擁有那個目的。顯然，目的性說明的解釋力並非來自其對未來效應的顯性指涉，而是來自其由此對「過去對那些未來效應的意向態度」的隱性指涉。簡言之，目的論說明只是普通因果說明的一個物種。生物功能的難題在於：這裏沒有有意圖的行動者。普賴爾不能訴諸上帝，也不能訴諸大自然母親的意圖或演化設計——那些誤導人的偽說明在科學上並不體面。

在普賴爾的文章中，他算是回應了目的論難題：他指出這是一條「關於人類（或動物、植物、昆蟲）的根本事實：它們高度關心生存與繁殖」。[6] 他把「終極意圖」這個神學問題，用「假定它是事實」的方式繞了過去。他還藉一個想像世界的例子主張：生物生命體的終極目的是可議的——那個世界的人類生命體寧願快樂地死去，也不願生存繁衍。我對普賴爾的辯護不太滿意，因為它相當薄弱：他只是對人性、或對生物生命體的一般本性，作了一個毫無根據的假定。任何主要宗教的信條都足以與他關於人類目的的想法相牴觸：例如，對基督徒而言，人的目的不是生存或繁殖，而是上天堂；對佛教徒而言，人的目的是輪迴轉世、證得涅槃。

我將以一個人類中心的視角回應尼安德爾的目的論難題：是我們——人類——把目的賦予自然。自然本身可以沒有任何目的，但這不意味着人類不能賦予自然某些目的。說到底，一切目的論意圖的有意識行動者，其終點是人，而不是上帝，也不是大自然母親。隨着現代科學的進展——基因工程、地質工程、氣候控制、太空殖民——人類終將擁有把自然塑造為我們想要的樣子的力量。屆時將不再有自然意圖，一切都是人工意圖；就目前而言，所謂自然意圖，不過是我們尚未想出控制辦法的人工意圖。總而言之：對母雞而言，蛋的功能是繁殖的手段；對人類而言，蛋的功能是早餐，而雞的功能是午餐或晚餐。普賴爾的學說是最有可能的功能解釋；我對它的小小修正是：人位於一切系統的中心，因此我們是有意識的行動者，而自然功能終將與人工功能大體等價——唯一的區別是，自然功能是由演化工程生成的。
