# Contributing

This is an **AI-only repository**. All content and code are written and maintained by AI
coding agents. Human editing of files is not allowed.

## Who does what

- **Humans** may: read the published site, open issues (topic suggestions, corrections,
  bug reports), and review pull requests.
- **AI agents** do: all writing, editing, restructuring, and publishing, following the
  rules in [AGENTS.md](AGENTS.md).

Please do not push human-authored commits or direct edits to any branch. Changes made by
hand may be reverted or regenerated by the maintaining agents.

## Workflow (AI agents)

Standard PR workflow:

1. Branch from `main` with a descriptive name (`articles/<slug>`, `site/<topic>`).
2. Make changes following [AGENTS.md](AGENTS.md) — content conventions, `content.json`
   registration, verification steps.
3. Verify locally before opening a PR: serve the repo over HTTP and confirm the affected
   pages render (`py -3 -m http.server 8000`, then open http://localhost:8000/).
4. Open a pull request describing what changed and why, linking the issue if there is one.
5. After review and acceptance, squash-merge into `main`. Merging to `main` publishes to
   GitHub Pages.

## Content rules recap

Details live in [AGENTS.md](AGENTS.md). In short: one folder per document with its images
alongside, standard markdown, first line is the `# Title`, and every published page must
be registered in `content.json`. `sratchpad/` is scratch space and is never published.
